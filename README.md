# 从 WordPress 导入 (import-from-wordpress)

将 WordPress WXR 导出 XML 中的内容导入 LinearPress，支持保留现有、覆盖冲突。

## 功能

- **文章与页面**：`post_type=post/page` 全部导入；Gutenberg 区块转换为 LinearPress 区块
  （paragraph / heading / blockquote / image / custom-html），不支持的区块转为段落文本或自定义 HTML 原样保留。
- **媒体文件**：从原 WordPress 站点拉取附件并存入媒体库（保留原发布日期），文章中的媒体引用自动重写；
  未安装「媒体库」插件时仅保留原始 WP 链接。
- **用户**：按作者登录名创建/复用账号（随机密码哈希，仅归档不可登录）；安装「多彩个人资料」时同步昵称等资料。
- **分类目录**：安装「高级文章列表」时导入分类并关联文章。
- **评论**：审核通过的导入为「已通过」，其余为「待审核」，保留作者、邮箱、IP 与时间。
- **站点信息**：名称 / 大小标题 / 描述 / 网址；当前站点配置为网址自动配置（autoDetect）时跳过网址部分；
  选项中选择「自动配置」则完全不导入站点信息。
- **浏览量**：`views` postmeta 导入为文章浏览量；置顶文章同步到高级文章列表。

## 使用

1. WordPress 后台 → 工具 → 导出 → 全部内容，保存 XML。
2. LinearPress 后台 → 插件 → 插件列表 →「从 WordPress 导入」→「导入 XML」。
3. 选择 XML，勾选选项后点击「开始导入」。

导入开始后进入特殊维护模式（**不会卸载/禁用任何插件**，导入需要与其它插件协作），
进度仅对发起者会话可见，其他人访问前台仍看到普通维护首页。完成后请检查各文章排版。

## 注意事项

- 导入一旦开始无法中止，耗时与内容量相关（一般 5~10 分钟）。
- 导入期间不要重启或部署站点，否则会中断导入（已导入部分保留，可重试续导）。
- 本插件无法保证与 WordPress 原站排版完美兼容；自定义区块（mdx 等）将以原始 HTML 保留。

## 依赖插件（可选）

| 步骤 | 依赖插件 | 缺失时行为 |
| --- | --- | --- |
| 媒体导入 | `media-library` | 跳过拉取，仅保留原始链接 |
| 分类目录 | `advanced-posts-list` | 不导入分类 |
| 作者资料 | `colorful-profiles` | 仅导入用户名/邮箱/密码哈希 |
